# 토스증권 월 적립식 투자 봇

## 대시보드 실행

```powershell
python -m invest_bot.dashboard
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. API 키 없이도 투자금 변경과 예시 잔고를 확인할 수 있습니다.

- 투자금 입력 → **투자금 저장**: `data/settings.json`에 저장되며 기존 `.env`의 금액보다 우선합니다. CLI 봇에도 다음 실행부터 적용됩니다.
- **잔고 새로고침**: `.env`의 토스 API 인증정보로 보유 수량·평가금액을 조회합니다. 키 변경 후에는 서버를 재시작하세요.
- **예시 잔고 보기**: 가상 데이터이며 실제 잔고로 저장되지 않습니다.
- 평가금액은 주식만 포함합니다. 현금/예수금은 포함하지 않습니다. 평가손익은 조회 환율 환산 기준이며 세금·비용·환차손익을 완전히 반영하지 않습니다.
- 기본 목표비중/배분 미리보기는 정상장 기준 참고값입니다. 현재 시장 신호가 아닙니다.
- 대시보드는 로컬 PC 전용이며 실주문 기능과 정기 실행 일정은 제공하지 않습니다.

대시보드 검증: `python -m unittest discover -s tests -p test_dashboard.py -v`

### 실제 토스증권 계좌 연결

대시보드는 계좌 비밀번호를 받지 않고 토스증권 WTS의 **설정 → Open API**에서 발급한 API 키를 사용합니다.

1. `.env.example`을 복사해 `.env` 파일을 만듭니다.
2. `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`에 발급값을 입력합니다. 계좌가 여러 개면 `TOSS_ACCOUNT_SEQ`도 입력합니다.
3. 토스증권 WTS의 Open API 허용 IP 목록에 이 PC의 공인 IP를 등록합니다.
4. 대시보드를 재시작하고 **실제 계좌 연결 확인**을 누릅니다.

상태가 `실제 계좌 연결됨`으로 바뀌면 잔고 새로고침으로 보유 주식의 수량·평가금액·비중을 볼 수 있습니다. 대시보드에는 주문 API 경로가 없어서 이 과정에서 매수·매도 주문을 만들지 않습니다.

`QQQ / TQQQ / SPY / SCHD` 전략을 월 100,000원으로 계산하는 개인용 도구입니다.

## 안전 원칙

- 기본값은 `DRY_RUN=true`입니다. 이 상태에서는 어떤 주문도 전송하지 않습니다.
- 실주문은 `DRY_RUN=false` **및** 실행 시 `--live`를 함께 지정해야 합니다.
- 매도 리밸런싱은 기본적으로 꺼져 있습니다. 초기 운용은 신규 적립금 매수만 합니다.
- API 비밀값은 `.env`에만 두고, 절대 저장소에 넣지 않습니다.

## 설치와 최초 실행

Python 3.11 이상이 필요합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python -m invest_bot run
```

토스증권 WTS의 **설정 → Open API**에서 `client_id`, `client_secret`, 허용 IP를 등록한 뒤 `.env`에 넣으세요. `TOSS_ACCOUNT_SEQ`는 비워도 됩니다. 프로그램이 첫 종합매매 계좌를 찾아 사용하지만, 여러 계좌가 있으면 명시하세요.

`run`은 QQQ 200일봉, TQQQ 200일봉, 보유자산과 USD 매수가능금액을 읽고 주문 계획을 `data/runs/`에 저장합니다. API 연결을 먼저 점검하려면:

```powershell
python -m invest_bot check
```

## 실거래 전환

최소 두 번의 `DRY_RUN` 결과와 앱의 잔고를 대조한 뒤 `.env`의 `DRY_RUN=false`로 바꾸고, 미국 정규장 중에만 다음처럼 실행합니다.

```powershell
python -m invest_bot run --live
```

토스 API의 소수점 매수는 달러 금액 시장가 주문입니다. 이 봇은 `orderAmount`를 사용합니다. 실주문 직전에는 월별 실행 저널을 먼저 기록하며, 같은 달 재실행은 차단합니다. 주문 도중 오류가 나면 자동 재시도를 하지 않고 저널과 토스 앱의 주문내역을 대조해야 합니다.

## 구현한 전략 해석

- 매월 예산: 100,000원. 실제 주문금액은 토스 참고 USD/KRW 환율로 환산하고 2% 현금 버퍼를 뺍니다.
- 강한 상승 / 정상 / 약화 / 하락의 비중은 프로젝트의 전략 문서를 따릅니다.
- 원문 의사코드에서 `QQQ > SMA175`가 `추세 약화`보다 먼저 평가되어 약화 상태가 도달 불가능했습니다. 이 구현은 강한 상승 → 추세 약화 → 정상 상승 → 하락 순으로 판정합니다.
- TQQQ 낙폭 확대는 `QQQ가 SMA175의 2% 이내이고 전일보다 상승`일 때만 허용합니다. 비중을 늘릴 때 다른 ETF 비중을 비례 축소해 TQQQ 목표치를 보존합니다.
- 매도 리밸런싱은 구현 범위에서 제외했습니다. 월 10만 원 규모에서는 신규 적립금 우선 방식이 더 적절합니다.

이 프로젝트는 개인용 기술 도구이며 투자 권유나 수익 보장이 아닙니다. TQQQ는 일일 3배 레버리지 ETF여서 장기 보유에도 큰 손실과 경로 의존성이 발생할 수 있습니다.
